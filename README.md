# Weather_tg_bot

Telegram-бот, который показывает текущую погоду и прогноз для любого города мира с интеграцией публичного API OpenWeatherMap.

Бот позволяет пользователю:
получать текущую погоду по названию города или геолокации;
получать графическую карточку с температурой и условиями;
смотреть подробный прогноз на завтра (утро, день, вечер);
получать рекомендации по одежде отдельно для девушки и парня;
автоматически распознавать город из произвольного текстового сообщения.

Проект использует внешний публичный API OpenWeatherMap (`/weather` и `/forecast`) и хранит секреты в `.env`-файле, исключённом из репозитория.

# Основной функционал

🌤 Получение текущей погоды
Запрос погоды по геолокации одним тапом
📅 Прогноз на завтра по нажатию inline-кнопки
🎨 Графическая карточка с динамическим фоном под условия
👗 Совет по одежде для девушки и парня
🌧 Вероятность осадков и подробные параметры
🛡 Защита от спама (rate limiting через middleware)

# Используемые технологии

Python 3.10+
aiogram 3.x (асинхронный фреймворк для Telegram Bot API)
aiohttp (HTTP-клиент)
Pillow (генерация карточек)
python-dotenv (переменные окружения)
OpenWeatherMap API

# Установка

```bash
pip install -r requirements.txt
```

Содержимое `requirements.txt`:

```
aiogram>=3.4,<4.0
aiohttp>=3.9,<4.0
python-dotenv>=1.0,<2.0
Pillow>=10.0,<12.0
```

# Настройка

Создай файл `.env` по образцу `.env.example`:

```
BOT_TOKEN=ВАШ_ТОКЕН_ОТ_BOTFATHER
OPENWEATHER_API_KEY=ВАШ_КЛЮЧ_OPENWEATHERMAP
```

Где взять ключи:

- `BOT_TOKEN` — у [@BotFather](https://t.me/BotFather) командой `/newbot`
- `OPENWEATHER_API_KEY` — на [home.openweathermap.org/api_keys](https://home.openweathermap.org/api_keys) (активируется ~1–2 часа)

# Запуск

```bash
python bot.py
```

При успешном старте в консоли появится `Bot is starting…`. Дальше открывай бота в Telegram и отправляй `/start`.

Для проверки логики без подключения к Telegram (только OpenWeatherMap и генерация карточки):

```bash
python test_local.py
```

Результат — файл `test_card.png` рядом с исходниками.

# Команды и кнопки

| Команда / действие       | Описание                                    |
| ------------------------ | ------------------------------------------- |
| `/start`                 | Запуск бота, приветствие, нижняя клавиатура |
| `/help`                  | Справка по функционалу                      |
| `/weather <город>`       | Погода в указанном городе                   |
| Текст с названием города | Воспринимается как название города          |
| Геолокация               | Погода в текущей точке                      |
| 📅 Прогноз на завтра     | Inline-кнопка под карточкой                 |
